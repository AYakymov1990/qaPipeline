# 129469 — Правки по оформлению заказа

> Текст задачі дослівно, як його надав QA 2026-11-03. Площадка за словами QA: «Правки делаются для Испанской версии сайта».

## Опис задачі

Правки по оформлению заказа

«País» - страна не определяется, хотя по ip известно. Нужно пересмотреть автоподстановку страны [Image #1].
«Apellido» стоит перед «Nombre». Для испанцев привычен обратный порядок. Поменять местами, сделать Nombre первым.
Codigo postal  - сделать читаемые ошибки валидации. Сейчас при любой валидации этого поля отображается ошибка на кол-во символов [Image #2].
Правки по селекту с выбором доставки и адресами:
если один способ доставки - селект Método de entrega убираем, а заголовок меняем с Entrega на Entrega a domicilio [Image #3]
если есть сохраненные адреса, добавляем селект с названием Direcciones guardadas [Image #4].
В поле Envío убрать тултип и вместо него писать Se calculará al introducir el código postal (до просчета доставки) [Image #5].

## Опис реалізації (вставлено QA)

1. Автоподстановка страны по IP
Обычные продавцы и раньше брали страну из IP. У дропшипперов с маппингом гость теперь тоже получает страну по IP, но только если она есть в списке стран селекта. Раньше страна у них всегда была пустой.
У продавцов только с Correos (1276260, тестовый 1520248) страна теперь всегда ES, независимо от IP. Раньше при не-испанском IP страна оставалась пустой при заблокированном селекте, и заказ нельзя было оформить.

Правило валидации страны теперь падает и тогда, когда выбранной страны нет среди опций селекта. Это кейс Genei с украинским IP или из сохранённого адреса: раньше селект выглядел пустым, ошибки страны не было, и пользователь видел только ошибку Genei «no disponible».

2.  Правки по селекту с выбором доставки и адресами
Если на ES/PT у продавца один способ доставки (не Multibravis), селект способа доставки скрыт, заголовок «Entrega a domicilio», а над страной показан отдельный селект «Direcciones guardadas». Если способов несколько (например, есть самовывоз), остаётся старый общий селект с адресами и способами, отдельного селекта адресов нет. Если есть только самовывоз, заголовок «Entrega». Селект «País» для Correos (19) и типа 18 теперь виден, заблокирован и показывает España.
У дропшипперов с маппингом сохранённые адреса фильтруются по странам, куда продавец доставляет: например, для Correos только ES. Раньше можно было выбрать UA-адрес и оформить заказ «Correos, Ucrania». Для этого добавлен хелпер getDropshipperAllowedCountries. Автовыбор адреса при загрузке у таких продавцов берёт первый адрес в разрешённой стране, а не просто первый в списке.

## Regression List [Front-end] (вставлено QA)

Автоподстановка страны по IP: Правила валидацию страны, проверить, чтобы заказ оформлялся на всех версиях и чтобы не пускало, если страна не заполнена.
На обычных продавцах ES/PT с одной доставкой Genei, а также с Genei и самовывозом, при ES или PT IP страна подставляется сама. С UA IP поле País пустое, при оплате появляется ошибка «País», а после выбора España заказ оформляется. У дропшипперов с разделением доставки по странам (1101133, 839297, тестовый 1520267) и у дропшипперов с одним кастомным способом доставки (тестовый 1520263) при PT или FR IP страна и цена есть сразу. С ES IP цена у них появляется после ввода индекса, с UA IP страна пустая. У дропшиппера, у которого есть только Correos (тестовый 1520248), при любом IP стоит заблокированная España, и цена есть сразу. Выбранная вручную страна сохраняется после модалки логина. Ложной ошибки «País» нет у Correos, кастомных способов, самовывоза, скрытого селекта страны, на PL, TR и испанских сайтах продавцов.
Имя перед фамилией: В чекауте ES/PT поля идут в порядке Nombre, Apellido, CIF на десктопе, планшете и телефоне. Ошибки и автозаполнение браузера попадают под свои поля. На странице заказа ES/PT имя выводится как «Имя Фамилия» у зарегистрированного и у гостя, и кнопка копирования копирует в том же порядке. На PL, TR, UA и испанских сайтах продавцов изменений нет.
Понятные ошибки индекса (Испания): Добавлено только для испании. Пустой индекс даёт «Indique el código postal», неполный индекс— «El codigo postal debe tener {0} dígitos», несуществующий индекс — «Este código postal no existe. Compruébelo». С индексами 28013, 08001 и 35001 (острова) город и цена заполняются. Для других стран тексты не поменялись
Текст в «Envío» вместо тултипа: На ES/PT сначала текст, затем спиннер, затем цена, и у «Envío» нет «?». При ошибке Genei снова показывается текст. На PL, TR и Partsinus «?» с тултипом на месте, а лейбл «Envío» 14px.
Правки по селекту с выбором доставки и адресами: При одном способе доставки (обычный продавец ES/PT только с Genei, дропшиппер с разделением доставки по странам, дропшиппер с одним кастомным способом и дропшиппер только с Correos) заголовок «Entrega a domicilio», и селекта способа нет. У авторизованного пользователя «Direcciones guardadas» стоит над страной, и первый адрес уже выбран. Смена адреса пересчитывает цену, а правка любого поля сбрасывает этот селект. При нескольких способах доставки (обычный продавец ES/PT с Genei и самовывозом, дропшиппер без маппинга) работает старый общий селект, и переключение между доставкой и самовывозом работает. Если у продавца есть только самовывоз, виден заголовок «Entrega» и выбор магазина. У дропшиппера только с Correos в списке только испанские адреса, а если их нет, селекта нет. У дропшиппера с разделением доставки по странам украинских адресов в списке нет, а маршрут соответствует стране адреса. У обычного продавца с Correos или типом доставки 18 поле País видно и заблокировано. На Multibravis и украинских площадках (Nova Poshta, Ukrposhta, Uklon) изменений нет.

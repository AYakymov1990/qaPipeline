> Джерело правди чек-листа. `03-checklist.xlsx` генерується з цього файлу скриптом `scripts/build_xlsx.py` — правки вносяться сюди, потім xlsx перегенеровується.

## Опис

- **Функціонал:** Інтеграція служби доставки Seur для обраних продавців на avtopro.es: розрахунок вартості за статичними тарифами, ТТН, етикетка, скасування, трекінг, логування; fallback на Genei.
- **Що змінено:** Для продавця 1082119 доставка в кошику рахується через Seur (тариф S-1 (24 H.) для Іспанії й Португалії, CLASSIC для Європи) плюс паливна надбавка, безпековий збір, доплати за вантаж і доплати Балеарів. Адреса й замовлення отримують тип 26 (Seur) замість 25 (Genei). Якщо Seur не може порахувати доставку, ціну рахує Genei і тип лишається 25. Продавець створює ТТН кнопкою «Замовлення відправлено», завантажує етикетку; при скасуванні замовлення сбор у SEUR скасовується. Тарифи й паливну надбавку в ітерації 1 завантажує розробник вручну; завантаження через API співробітниками з BPanel-роллю — ітерація 2 (рішення QA 2026-11-08). Для інших продавців нічого не змінюється.

## Як система бере вагу й габарити (що важливо для пошуку)

1. **Тільки рядки PartAttributes із власними замірами**: `VolumeM3 > 0` і рядок проходить перевірку посилки — кожна сторона ≤ 300 см, вага ≤ 200 кг, обʼємна вага ≤ 200 кг, щільність ≤ 12 000 кг/м³. Інакше система бере аналоги, AI або коробку за замовчуванням, і ціну наперед не порахувати.
2. **Сторона** = `LengthCm`, а якщо він 0 — `LengthMm / 10` (так само `Width*`, `Height*`). Система **округлює кожну сторону вгору до цілого см і додає 2 см** пакування (одна позиція в кошику).
3. **Розрахункова вага** = max(реальна `WeightKg`, обʼємна з пакуванням (Д+2)×(Ш+2)×(В+2) / 5000). Вага не округлюється.
4. **Детерміновано** (без втручання AI) — тільки рядки з `suspicious: false`: обʼємна вага за даними бази (без пакування) < 2 × реальної **і** max(обʼємна, реальна) < 30 кг.
5. **Рядки ≥ 30 кг — завжди `suspicious`**: AI може замінити габарити, але **вага лишається з рядка**. Тому правила за реальною вагою (Fuera de Norma A / B, ліміт CLASSIC 31,5 кг) перевіряються й на таких деталях, а суму звіряємо з логом «Genei package composition» (`Source`, `Used`). Підходять і рядки без власних замірів, у яких задекларована вага (як T21).
6. **Альтернатива для меж ваги — кількість.** N однакових деталей → вага сумується точно (2 × T05 = 12,10 кг — підтверджено прогоном). Коробку система рахує за обʼємом / 0,7 + 2 см, тому для такої перевірки потрібні малі деталі.
7. Деталь має бути в каталозі avtopro.es (картка `/repuesto-…/`), інакше позицію в прайсі не видно.

**Що повернути по кожному кандидату** (2–3 на рядок): код, бренд, кросгрупа і відповідь QA-ендпоінта — `source`, `rejectReason`, `suspicious`, `usedDimensions`.

## Чого через базу не перевірити

- **Сторона понад 300 см** (Fuera de Norma B за довжиною, `ShipmentNotEligible` для довжини > 300): рядок PartAttributes зі стороною > 300 см система відкидає (`SideOverLimit`) і бере інші дані — лишається юніт-тестам.
- **Сума сторін понад 500 см** (Fuera de Norma B за розміром): теоретично можлива лише для дуже пласкої деталі (наприклад, 290×200×12 см, обʼємна ≈ 165 кг), на практиці в базі навряд чи є — шукати за бажанням.

## 1. Продуктова задача

**[Вимога] Мета:** інтегрувати нову службу доставки Seur і відкрити її для обраних продавців.

**[Вимога] Обмеження й рішення:**
- Для інших продавців Seur прихований. Треба лишити можливість швидко відкрити його ширше після тестування.
- Спочатку Seur вмикається для звичайного (не дропшипера) тестового продавця **1082119**. Перед релізом розробники вручну внесуть у код інші акаунти.
- Візуально для покупця нічого не змінюється. Для обраних продавців розрахунок іде через Seur, а не Genei. У замовленні має бути тип доставки **26 (Seur)**, а не **25 (Genei)**.
- Потрібний функціонал:
  - розрахунок вартості доставки;
  - автоматична генерація ТТН;
  - трекінг статусів;
  - скасування доставки в Seur при скасуванні замовлення, щоб не платити зайвого;
  - логування за аналогією з Genei, щоб після релізу відстежувати розраховану вартість і якість доставки.
- Оплати готівкою для цього функціоналу немає.

**[Вимога] Зміни після початку розробки:**
1. SEUR оновив API: розрахунок ціни через API (`valuate`) більше не працює. Ціна тепер рахується за **статичними тарифами**.
2. Тарифи оновлюються раз на місяць, 1-го числа. Відділ Sales SEUR надсилає два PDF на запит: національний і міжнародний (Європа).
3. Паливна (енергетична) надбавка оновлюється раз на місяць: https://www.seur.com/es/tasa-de-energia/
4. Зони від розробника:
   - **Medio España** — Galicia, Asturias, Castilla y León, Madrid;
   - **Largo España** — решта півострова й Португалія.
5. **Погоджено:** у всіх випадках, коли Seur не може порахувати доставку, ціну рахує Genei.
6. **Погоджено:** тарифи й паливну надбавку поки вносить розробник вручну через API.
7. Для реальних кодів деталей вага й габарити з БД (каталог) мають пріоритет над значеннями з прайсу продавця. Тому для перевірки цін використовується калькулятор (див. розділ 6): тестувальник вписує габарити, які фактично взяла система.

### 3.2. Розрахунок у кошику

**[Код]** Фронтенд (`cart/models/Model.js`, `getDeliveryPrice`):
- Для 1082119 викликає `GET /api/v1/cart/seur-delivery-cost?sellerId&countryIso&postalCode&itemsId`, для інших продавців — розрахунок Genei.
- Попередній запит скасовується через `AbortController`. Відповідь, що прийшла запізно, ігнорується за лічильником `deliveryRequestId`.
- При зміні країни ціна скидається.
- З відповіді береться `Price`, `CityName` (місто підставляється у форму) і `DeliveryTypeId` (у `selectedDeliveryTypeId`).
- `AddressFormContainer.jsx` для продавців із `SEUR_SELLER_IDS` зберігає адресу з тим типом, який повернув розрахунок (26 або 25). Якщо запит перервано, лишається тип із форми.

**[Код]** Бекенд (`ShoppingCartController.GetSeurDeliveryCost`):
- Викликає `DeliveryPriceManager.GetSeurDeliveryCostAsync`. Відповідь — `SeurPriceResponseDTO { Price, Currency, Warning, DeliveryHours, CityName, DeliveryTypeId = 26 }`.
- **Fallback на Genei** спрацьовує при `InvalidOperationException` (це й `SeurPricingException`), `SeurApiRequestException`, `HttpRequestException`, а також `OperationCanceledException` не від клієнта. Пишеться лог `FellBackToGenei`, далі викликається `GetGeneiDeliveryCostAsync`, відповідь має `DeliveryTypeId = 25`.
- Якщо Genei теж не порахував, повертається 400 `{reason}`. Фронтенд тоді показує «доставка недоступна» (`DeliveryNotAvailableText`).
- Ціна Seur повертається **без IVA**, як і `DisplayPrice` у Genei.
- **Кеш ціни (quote):** `SeurDeliveryManager.HonourQuotedPriceAsync`. Ключ — `seur:quote:{userId}:{sellerId}:{COUNTRY}:{POSTAL}:{sha256(id:count позицій)}`, TTL **2 години** у Redis. Показується `min(збережена, нова)`: протягом 2 годин ціна може тільки зменшитися.
- Аналітична подія `SeurCheckoutAnalyticsEvent` (Quoted / NoDeliveryOffered) відправляється не частіше ніж раз на 2 години для того самого кошика.

### 3.3. Весогабарити посилки

**[Код]** `Common/Library/Delivery/ShipmentDetailsManager.cs` — спільний для Genei і Seur. Порядок вибору даних для кожної позиції:
1. Атрибути деталі з БД (`PartAttributes`, за кодом і брендом / кросгрупою). Беруться як є, якщо їх можна відправити посилкою.
   - «Підозрілий» рядок (об'ємна вага ≥ 2 × реальної або вага ≥ 30 кг) може бути скоригований відповіддю AI: габарити від AI, вага з рядка.
2. Медіана виміряних аналогів у кросгрупі.
3. Відповідь AI (кеш; у кошику чекає до 3 с).
4. Типова деталь класу.
5. Коробка за замовчуванням **30×25×15 см, 3 кг** (вага береться задекларована, якщо вона правдоподібна).

- Позиції об'єднуються в одну посилку (`GetMergedPackage`). Для однієї позиції до кожного боку додається **2 см пакування** з округленням вгору; вага не менше 0,05 кг.
- Лог складу посилки: `GeneiLogSvc.GetDeliveryPrice`, повідомлення «Genei package composition», для кожної позиції поля `Source`, `Cat` (з каталогу), `Used = Д×Ш×В/вага` (без пакування).
- ⚠️ **Ризик:** звідки атрибути беруться в БД (SQL-процедура `p_partattributes_get_by_shortnr_and_manufacture_v2`), з репозиторію не видно. Вага й габарити з прайсу продавця (колонки Peso/Profundidad/Ancho/Alto) зберігаються в позиції складу. Для реальних кодів пріоритет мають дані каталогу.

### 3.4. Алгоритм ціни Seur

**[Код]** `Common/Library/Seur/SeurApiManager.cs` → `GetPriceAsync`. Перевірки йдуть по черзі; кожна відмова означає `SeurPricingException` і fallback на Genei:

1. **Маршрути з митницею не підтримуються:** GB/UK, CH, NO, RS, BA як країна відправлення чи призначення → `ShipmentNotEligible`. Код розрахунку митного оформлення є, але до нього не доходить.
2. **Недоставні напрямки** → `NotDeliverableDestination`:
   - ES з індексами `35`, `38` (Канари), `51` (Ceuta), `52` (Melilla);
   - PT з індексом на `9` (Мадейра, Азори).
3. **Тип тарифу:** ES і PT → `National`, паливна надбавка `NationalAndPortugal`; решта країн → `Europe`, надбавка `International`.
4. **Паливна надбавка:** потрібна рівно одна активна ставка на **поточний місяць за UTC** (`Month == 1-ше число`).
   - Дві активні → `RateUnavailable`.
   - Немає → `RateUnavailable`. Виняток — створення ТТН (`AllowMissingFuelSurchargeRate = true`), там надбавка 0 %.
5. **Вага:** для кожної посилки `max(реальна, Д×Ш×В / 5000)` (200 кг/м³).
6. **Довжина понад 300 см** (будь-який напрямок) → `ShipmentNotEligible`.
7. **Європа, ліміти CLASSIC:** реальна вага ≤ 31,5 кг, найдовша сторона ≤ 175 см, обхват `Д + 2Ш + 2В` ≤ 300 см. Інакше `ShipmentNotEligible`.
8. **Місто отримувача** через API SEUR `GET pic/v1/cities`. Не знайдено → `NoShipMethod`.
9. **Зона:**
   - ES з індексом `07` → «Largo Baleares»;
   - ES з префіксами Medio `05, 09, 15, 24, 27, 28, 32, 33, 34, 36, 37, 40, 42, 47, 49` → «Medio España Penínsular»;
   - решта ES і PT → «Largo España Penínsular»;
   - Європа → назва з `SeurTariffZones.EuropeByCountry`, наприклад «ZONA 1 Francia - HOME».
10. **Послуга:**
    - National: місто відправника → `GET pic/v1/ship-methods` між депо. Фільтр: ProductCode 2, ServiceCode 3/9/1/15, без SAT/MKT+/*B2C, підходить за вагою, кількістю й габаритами. Сортування S-10 → S-13 → S-24 → S-48. Береться **найшвидша послуга, для якої є активний тарифний діапазон**.
    - Відповідність послуг тарифам: 3 → «S-10 [P,L]», 9 → «S-13:30 [P,L]», 1/15 → «S-1 (24 H.) X [P,L]». У PDF 2027 є лише S-1, тому фактично вибирається S-1.
    - Europe: завжди CLASSIC `77/70`, для GB `77/116`.
11. **Діапазон тарифу:** активний рядок, де `MinWeightKgExclusive < вага ≤ MaxWeightKgInclusive`. Немає → `NoShipMethod`. Ціна ≤ 0 → `RateUnavailable`.
12. **Понад межу** (рядок має `PricePerKg` і `PerKgFromWeightKg`): `BasePrice + (вага − PerKgFrom) × PricePerKg`, округлення до 0,01 (AwayFromZero). Вага **дробова**, вгору не округлюється.
13. **Доплати:**
    - паливна надбавка = `round(тариф × % / 100, 2)`, лише на тариф;
    - безпековий збір: **0,30 €** National, **0,40 €** Europe;
    - доплата за вантаж (`SeurHandlingClassifier`, за габаритами з пакуванням і реальною вагою, одна найсуворіша категорія на посилку):
      - **Fuera de Norma B 99 €:** вага > 60 кг, або сторона > 300 см, або сума сторін > 500 см;
      - **Fuera de Norma A 49 €:** вага > 40 кг, або сторона > 175 см, або сума > 300 см;
      - **No Encintable 1,50 €:** вага < 40 кг і сторона > 100 см;
    - Балеари: +3 € для всіх міст, крім Palma («PALMA» / «PALMA DE MALLORCA» за назвою міста з API); для індексів `077..`/`078..` (Menorca, Ibiza/Formentera) ще 7,98 € + `round(вага × 0,25, 2)`.
14. **Разом** (без IVA) = тариф + паливна надбавка + безпековий збір + доплата за вантаж + доплата Балеарів (+ митне оформлення, яке зараз недосяжне).
15. **Лог `Priced`** (`Seur:GetDeliveryPrice`): ServiceCode/ProductCode, ShippingMethodName, DestinationName, ActualWeightKg, VolumetricWeightKg, Weight, Price, Surcharge, DestinationSurcharge, FuelSurcharge, SecurityFee, Handling, IsTest. Відсоток і місяць паливної надбавки в лог не пишуться.

- ⚠️ **Ризик:** імпорту PDF немає, JSON готують вручну. Дати початку дії тарифу немає, тому тарифи нового місяця треба внести рівно 1-го числа.
- ⚠️ **Ризик:** паливна надбавка вибирається за місяцем за UTC. У першу годину (взимку) чи дві (влітку) 1-го числа за Мадридом береться ставка попереднього місяця.
- ⚠️ **Ризик:** якщо на поточний місяць надбавку не внесли, Seur для всіх покупців без попередження перемикається на Genei (погоджений fallback, але це треба моніторити).

### 3.6. Оформлення замовлення

**[Код]** `OrderManager` (checkout):
- Адреса типу 26: продавець із `s_seurSellers` → розрахунок Seur. Рекалві з типом 26 → розрахунок Genei.
- Seur-розрахунок виконується, лише якщо весогабарити визначено для всіх одиниць товару і вибрано магазин.
  - ⚠️ **Ризик:** інакше `DeliveryPrice` не встановлюється, і в замовленні може бути 0 €.
- `seurPrice = GetPriceAsync(...)` — тут **немає** fallback на Genei і немає `AllowMissingFuelSurchargeRate`.
  - ⚠️ **Ризик:** якщо надбавку прибрали між розрахунком у кошику й оформленням, оформлення падає.
- `quoted = GetQuotedPriceAsync(...)` (кеш кошика). Якщо його немає, помилка «SEUR cart quote has expired. Refresh the cart delivery price before checkout.»
  - ⚠️ **Ризик:** як інтерфейс показує цю помилку, з коду не видно.
- `order.DeliveryPrice = round(min(seurPrice, quoted), 2)`, лог `Seur:Checkout` (Priced, CartPrice, CheckoutPrice).

### 3.7. ТТН, етикетка, скасування, трекінг

**[Код]**
- **Створення ТТН:** `OrderActionManager.DepartureConfirmationAsync`, кнопка продавця «Замовлення відправлено», для типу Seur.
  - Неоплачена передоплата → помилка «Order cannot be confirmed with delivery until it is paid.».
  - `SeurDeliveryManager.CreateShipmentAsync` спершу повторно рахує ціну (надбавка може бути відсутня) і бере звідти ServiceCode/ProductCode, тобто ту саму послугу, що й для ціни.
  - Параметри сбору: `Ref = "AVTO-{orderId}"`, дата забору — наступний робочий день 10:00, `Label = true`, `Payer = "ORD"`.
  - Customer: «ABPWORLD», NIF B72396302; у тесті «Avtopro Test Seller», CCC тестовий.
  - Parcels — одна об'єднана посилка. Країни нормалізуються (UK → GB, EL → GR). Маршрути з митницею відхиляються.
  - Номер ТТН (CollectionRef) записується в замовлення (`PatchTrackingInfoAsync`), лог `CollectionCreated`.
- **Етикетка:** у продавця з'являється дія `DownloadLabel` для Seur, якщо є номер ТТН і продавець зі списку (`SellerOrderActionResolver`). PDF приходить з `GET pic/v1/labels`. Для тестових номерів ТТН етикетки немає. Окремо виправлено продавця в `OrderActionsController.GetShipmentLabelAsync`, це стосується й Genei.

1. ❓ **Склад ціни.** Безпековий збір 0,30 € для відправлень по Іспанії (у національному PDF його немає, 0,30 € там вказано для міжнародних). Як показувати IVA покупцю (так само, як для Genei?). Чи прийнятно на старті не враховувати доплати SEUR:
   - віддалені зони +3,30 €;
   - No Apilable 7,50 €;
   - Fuera de Norma B для неупакованих бамперів і вихлопних труб;
   - +0,20 € за кожне місце понад перше;

## 8. Ризики для фокусу тестування (зведено)

1. Ціна 0 € в замовленні, якщо весогабарити визначено не для всіх товарів.
2. Помилка при оформленні без fallback: немає надбавки або минуло понад 2 години від розрахунку («SEUR cart quote has expired»). Як цю помилку показує інтерфейс, невідомо.
3. Протягом 2 годин кеш показує меншу з цін, тож підвищення тарифу чи надбавки покупець не побачить.
4. Тихий перехід усіх покупців на Genei, якщо не внесено надбавку чи тариф або в назві зони National одруківка.
5. Зміщення місяця надбавки через UTC.
6. Кнопка оформлення не блокується для типу 26 при помилці розрахунку.
7. Збережені адреси Seur не показуються для 1082119.
8. Список продавців Seur у трьох місцях; фронтенд підтримує лише одного продавця.
9. Для реальних кодів вага й габарити беруться з каталогу або AI, а не з прайсу, тому ціну звіряти через калькулятор.
10. Регресія Genei: переписано спільний `ShipmentDetailsManager`, `GeneiDeliveryManager`, договір дистанційного продажу, завантаження етикетки продавцем.

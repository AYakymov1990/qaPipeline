`GET /api/v1/cart/seur-delivery-cost` для T01 — усе через Genei (тип 25):

- Запит сторінки: `GET /api/v1/product-card/delivery-cost?descriptor=0986452024;96;0000;445949&price=9.9&deliveryType=26` → 200 `{"assessedCost":9.9,"cost":10,…}`. Раніше було `deliveryType=25` → 6.1.
- Для порівняння той самий запит з `deliveryType=25` → `cost` 6.1.
- Скриншот — `bug004-card-10eur.png`.

## BUG-001 — подробиці

- `GET /api/v1/addresses` зі сторінки оформлення 1082119 — 292 адреси, серед них тип 26: 1959420 («28004»), 1922980, 2040246 («Calle Seur QA 8»), 2040249, 2040250, 2042602 («28001 … - Test Ad»). Раніше жодної з типом 26.
- «Entrega a domicilio» → «Direcciones guardadas»: «España, 28004, Madrid, Calle Ruiz de Alarcón, 26» (×2) і «España, 28001, MADRID, Calle Ruiz de Alarcón, 26 - Test Ad» (тип 26). Вибір останньої → «28001», «MADRID» підставились, запит `seur-delivery-cost?…postalCode=28001` → тип 25, 5.91 (блокер вище).
- Автоматично підставилась «28004», «Calle Ruiz de Alarcón, 26» — така вулиця є і з типом 25 (2039845), і з типом 26 (1959420); яка саме — не встановлено.
- «Perfiles de contacto» → «Direcciones» не перевірено.
- Скриншот — `bug001-saved-type26-genei-price.png`.

## BUG-003 — подробиці

- Замовлення 10774398 — уже «Rejected» (2026-11-09, «cancelado por el vendedor» — автоскасування); перевірено на **10774403** (оформлене 2026-11-06, T01 / «28001», тип Seur, «WaitingDeparture», «Envío» 5,76EUR).
- «PEDIDO ENTREGADO» → `PUT /api/v1/orders/10774403/departure-confirmation` → **400** `{"Message":"No se ha podido crear el envío. Inténtalo de nuevo o contacta con soporte.","Code":null}` (09:16:38 і 09:16:55 UTC). Статус лишився «WaitingDeparture», `TrackingNumber` null.
- Обмеження: замовлення створене на старій збірці; нове замовлення Seur створити неможливо, поки розрахунок іде через Genei.
- Скриншот — `bug003-10774403-400.png`.

## Спроба повного флоу BUG-003 (09:19 UTC) — BLOCKED

QA попросив пройти повний флоу (нове замовлення Seur → оплата → «CONFIRMAR» → «PEDIDO ENTREGADO»). Перед оформленням перевірено розрахунок:
- покупець 1075831: 28001 → 5.91, тип 25; 08001 → 6.10, тип 25;
- гість (чистий контекст, новий кошик `itemsId` 29168901): ES 28001 → 5.91, тип 25; ES 08001 → 6.10, тип 25; PT 1000-001 → 8.69, «Lisboa», тип 25.

Seur не рахує ні для покупця, ні для гостя, ні для PT → нове замовлення отримало б тип 25 (Genei), а «Замовлення відправлено» пішло б через Genei. Повний флоу BUG-003 на цій збірці неможливий; замовлення не створювалось.

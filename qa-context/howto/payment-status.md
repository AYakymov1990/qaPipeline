# Як перевірити стан грошей замовлення (Профіт)

| | |
| --- | --- |
| Коли знадобиться | будь-яка перевірка грошей за життя замовлення: холд, списання, зарахування продавцю, повернення покупцю при скасуванні |
| Площадки | правила руху грошей нижче — ES (30) і PT (618); сторінка Профіту — для будь-якого замовлення |
| Роль | QA (окремий вхід на сторінку не описано) |
| Агенту можна виконувати | так — QA дозволив відкривати цю сторінку через Playwright і перевіряти статуси (2026-11-08) |
| Перевірено | ще ні — рецепт зі слів QA |
| Джерело | [зі слів QA, 2026-11-08, задача 127593] |

## Кроки

1. Взяти номер замовлення.
2. Відкрити в новій вкладці `https://prft.avto.pro/s/CheckPaymentStatus?orderid=<номер замовлення>`.
3. Знайти блок «СТАТУС ВНУТРИ СИСТЕМЫ ПРОФИТ»: «ID», «Статус», «Мерчант», «WalletId», «Касса».

## Як читати результат

- «Касса» «Тестовое окружение» — тестовий контур оплати (замовлення тестового користувача).
- «Статус»: `holded` — кошти заморожено; `succeeded` — холд списано, гроші зараховано продавцю (кінцевий статус); `reversed` — повернення покупцю; `success` — успішне підтвердження холда (за wiki).
- Надпис «Оплачен» у картці замовлення **не** означає, що холд списано, — дивитися тільки Профіт.
- Зарахування продавцю видно в кабінеті продавця: «Finanzas» → «Historial de operaciones».

## Очікувані статуси за сценарієм (ES, PT)

| Сценарій | Профіт |
| --- | --- |
| Оплачено, продавець ще не підтвердив; після «CONFIRMAR» | `holded` |
| Дія відправлення / ТТН (Seur «PEDIDO ENTREGADO», Genei «PREPARADO»), дроп — «SE HA GENERADO EL PEDIDO» | `succeeded` |
| Скасування (ручне чи автоматичне), поки `holded` | `reversed` |
| Скасування після `succeeded` | лишається `succeeded`; повернення покупець обговорює з продавцем або підтримкою |

## Особливості

- Не записувати «WalletId» та інші ідентифікатори платежу в артефакти задачі — достатньо статусу.

# Як отримати потрібну країну за IP (геолокацію покупця)

| | |
| --- | --- |
| Коли знадобиться | Перевірки, де поведінка залежить від країни покупця за IP: автопідстановка «País» у чекауті, ціни й доставка за країною, контент за геолокацією |
| Площадки | всі |
| Роль | будь-яка (гість або тестовий користувач з `.env`) |
| Агенту можна виконувати | так — cookie виставляється як передумова кейсу (Playwright: `context.addCookies`) |
| Перевірено | ще ні — рецепт зі слів QA |
| Джерело | [зі слів QA, 2026-11-04, задача 129469] |

## Передумови

- Стенд відкривається з фіксованого IP, який дає доступ до тестової площадки. Справжній IP не змінюємо — країну підміняє cookie.

## IP за країнами

| Країна | Місто | IP |
| --- | --- | --- |
| Україна | Київ | 185.237.74.247 |
| Україна | Запоріжжя | 104.28.198.34 |
| Україна | Львів | 5.59.198.144 |
| Україна | Харків | 195.162.65.195 |
| Іспанія | Мадрид | 2.16.38.140 |
| Португалія | Лісабон | 46.189.153.66 |

Інших країн у таблиці немає (напр. Франція, Туреччина, Польща). Їхні IP беремо з відкритого доступу (зі слів QA). Перед використанням перевіряємо: `CountryISO` має дорівнювати потрібній країні. Перевірений IP — додати в таблицю.

## Кроки

1. Відкрити сторінку площадки на стенді.
2. Додати cookie `debug_ip` зі значенням IP із таблиці. Наприклад, через DevTools → Application → Cookies → домен сторінки → нова cookie `debug_ip` = `2.16.38.140`. [ПРИПУЩЕННЯ] Так само можна в консолі: `document.cookie = "debug_ip=2.16.38.140; path=/"`.
3. Перезавантажити сторінку.

## Як перевірити результат

- У консолі `avtopro.geolocation.CountryISO` повертає код країни IP (для 2.16.38.140 — `"ES"`).

## Особливості площадок

- Не описано.

## Обмеження

- `debug_ip` змінює тільки геолокацію (`LocationHelper`) і IP в окремих контролерах (кошик, картка товару, відгуки). **Ліміт пошуку за держномером ES його не враховує** — там IP береться з `X-Forwarded-For` / адреси зʼєднання; для перевірки ліміту на IP потрібна інша реальна мережа [код `SearchEngineController.cs:250`–`266`, `LocationHelper.cs:34`; задача 129318, 2026-11-11].

## Відомі проблеми

- Cookie лишається в браузері: щоб повернути справжню геолокацію, видаліть `debug_ip`.
- Cookie виставлено, а `CountryISO` не змінився — перевірте, що cookie додано на домен відкритої площадки, і перезавантажте сторінку.

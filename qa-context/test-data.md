# Тестові дані

> Які дані є на тестовому стенді і як їх отримати. Без паролів і реальних персональних даних.

## Головне правило

Тестовий режим вмикає **користувач**, а не стенд. Пісочниця Stripe Connect і тестовий контур Recalvi працюють тільки для користувачів зі `StaticUserHelper.TestUsers`. Під будь-яким іншим акаунтом на стенді працюють бойові контури [CodeWiki].

## Доступ до стенду

- Фільтр за IP + пароль (`TEST_ENV_PASSWORD` у `.env`); пароль зберігається в cookie `TestEnvAccessToken` на 7 днів.
- Тестові продавці приховані у видачі, поки немає cookie `showTestUsers`.

## Акаунти

| Роль | Змінні в .env | Площадки | Примітки |
| --- | --- | --- | --- |
| Покупець без знижки | TEST_BUYER_0_* | | |
| Покупець 5% | TEST_BUYER_5_* | | |
| Продавець 20% | TEST_SELLER_20_* | | |
| Автосервіс 20% | TEST_SERVICE_20_* | ua | верифікація СТО тільки на UA |

## Товари

| Що | Приклад (артикул / VIN / назва) | Площадка | Продавець | Примітки |
| --- | --- | --- | --- | --- |
| | | | тестовий | видно тільки з cookie `showTestUsers` |

## Оплата

- Stripe, тестовий режим, тестові картки з [документації Stripe](https://docs.stripe.com/testing) — тільки під тестовим користувачем.
- ImageOptimizer пісочниці не має — завантаження зображень іде в бойовий сервіс.

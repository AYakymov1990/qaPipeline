## Кошик, замовлення, оплата

| Термін | Що це | Не плутати |
| --- | --- | --- |
| Група кошика | Позиції одного продавця; з них оформлюється одне замовлення | |
| Розшарений кошик | Кошик, який збирач (зазвичай СТО) надсилає клієнту. За нього нараховується кешбек-PRO | |
| Покинутий кошик | Кошик, за яким не оформили замовлення. Має статуси і нагадування | |
| Замовлення | Угода покупця з продавцем, статуси — `OrderStatusEnum`. У кожного статусу є дедлайн (TTL), після якого працюють автопереходи й автоскасування | |
| Безпечна угода | Оплата через AvtoPro з повною або частковою передоплатою. Гроші заморожуються і переходять продавцю після завершення замовлення | |
| NewFlow («БУ v2.0») | Ознака замовлення за новою схемою. Без неї фонові задачі змінюють статус, але не застосовують санкції й повернення | |
| Холд | Заморожена передоплата покупця. Підтверджується — гроші йдуть продавцю; повертається — повернення покупцю | з оплатою (списанням) |
| Накладні витрати | Часткове утримання з покупця при скасуванні або автоскасуванні замовлення | |
| Відкладена виплата | Для доставки «свій спосіб», самовивозу і Uklon гроші продавцю виплачуються пізніше | з відкладеним платежем |
| Код підтвердження отримання | 6 цифр, які покупець називає при отриманні замовлення | |
| Профіт | Внутрішній платіжний сервіс компанії. Через нього проходять LiqPay, Monobank («Plata by mono») і Stripe | |
| Stripe / ABPWORLD | Еквайринг для європейських площадок. Тестова група ABPWORLD-TEST обробляється як бойова | |
| Відкладений платіж (PayCredit) | Кредитна лінія AvtoPro продавцю на 1–500 € (ES). Ще три назви в коді й ресурсах: «Відстрочена оплата», «Бонусний рахунок», «Оплата бонусами в кредит» | з відкладеною виплатою |
